# Cosmic Portfolio Studio

Create a modern, responsive, and clean personal portfolio website.

Design & Theme:

Use a dark mode design with a blue-and-purple color palette (e.g., dark background, smooth gradients transitioning from deep blue to purple, and neon or glowing accents on buttons and headings).

The design must be clean and minimalist, featuring modern fonts, rounded corners (rounded-xl), subtle shadows, and smooth hover effects.

Structure & Sections:

Hero Section: An impactful headline with a short description of what I do, and two primary action buttons ("View Work" and "Contact").

Showcase / Portfolio (My Work): A clean grid showcasing examples of my projects. Each card should include an image/preview, title, short description, and a link/button to details.

Freebies Section (Free Resources): A dedicated section for digital assets, tools, files, or guides that I offer completely for free, complete with a download button.

Pricing: Clear pricing packages or services displayed in card layouts, with one package highlighted as the most popular option.

FAQ (Frequently Asked Questions): An interactive accordion-style list with expandable questions and answers addressing client queries.

Checkout / Payment Section: A clean order form or section featuring a simulated payment integration (e.g., a "Checkout / Pay" button with credit card icons or a Stripe/PayPal-style interface).

Contact & Footer: A functional contact form and links to social media profiles.

Technical Requirements:

Make it fully interactive with smooth transitions, responsive mobile layout, and working UI states.
